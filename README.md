# Engineer360 🚀

**Engineer360** is an AI-powered platform designed to help engineering students understand their skills, identify skill gaps, and explore personalized learning paths and career opportunities.

## ✨ Features

- Skill assessment and analysis
- Skill-gap identification
- Personalized learning recommendations
- Career-oriented guidance for engineering students

## 🛠️ Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Python
- FastAPI

**Database**
- SQLite
- SQLAlchemy

## 🚀 Getting Started

1. Clone this repository.
2. Install the Python dependencies listed in `backend/requirements.txt`.
3. Configure and run the FastAPI backend.
4. Open the frontend using the appropriate local server or setup.

Detailed setup instructions will be added as the project is finalized.
